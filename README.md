The Midnight Vault — a top-down heist game in three rooms. You are the thief: slip past patrolling guards and sweeping ceiling cameras, pocket every gold loot, and leave through the green EXIT before the alarm hits 100. Guards have vision cones and chase when the alarm runs high; display cases and statues block their sight. Sneak (Shift) to shrink a guard's sight — cameras don't care. Level 3 adds blinking laser beams.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests, all art and sound drawn and synthesized in code.
